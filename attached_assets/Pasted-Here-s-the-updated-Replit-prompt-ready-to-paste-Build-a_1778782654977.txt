**Form submission flow:**

1. User clicks Download the Framework
2. Client-side validation runs — all five fields must be complete and email must be valid format and LinkedIn URL must begin with linkedin.com or www.linkedin.com
3. If validation fails show inline error messages below the relevant fields in red (#C62828) — do not submit
4. If validation passes POST the form data to the server
5. Server submits the lead to HubSpot Forms API v3 using these environment variables:
   - HUBSPOT_PORTAL_ID
   - HUBSPOT_FORM_GUID
6. Map the fields exactly as follows:
   - First Name → firstname
   - Last Name → lastname
   - Company → company
   - Email → email
   - LinkedIn URL → linkedin_bio
   - Hidden field → last_downloaded_asset = Scale or Transform Whitepaper
7. On successful HubSpot response trigger the PDF download automatically in the browser — the PDF is stored at /public/RZS_Scale_or_Transform.pdf
8. Show a brief success message above the form: "Your download is starting. Check your downloads folder."
9. If HubSpot submission fails still trigger the PDF download but log the error server-side — do not block the user from getting the file
